# STATUS.md — PryScraper

> Where we are RIGHT NOW. Update before each commit (see AGENTS.md).

## Current Phase
**phase_0_hardening_complete** — v3.0.0 shipped; MCP server is the primary
product surface, x402 payments at production hardening, scraping engine at a
15-tier adaptive fallback chain. Now in post-release hardening + audit burn-down.

## What Works
- **Scraping engine** — 15-tier anti-detection fallback chain (direct HTTP →
  TLS impersonation → cloudscraper → FlareSolverr → stealth browsers → Tor →
  proxies → Archive.org → AI visual → mobile API → GraphQL), per-domain
  adaptive tier memory + circuit breakers.
- **MCP server** — 76 tools across 33 categories; 110 pre-built templates;
  combined tool executor (actor + 21 domain dispatchers); Redis-backed session
  store for horizontal scaling (in-memory fallback preserved).
- **x402 payments** — HTTP 402 pay-per-call, server-authoritative pricing (64
  priced ops), EIP-7702 self-verify + Solana, Postgres settlement ledger with
  JSONL audit trail, offline-mode guard.
- **CLI** — `pry` / `pry-mcp` / `pryscraper-mcp` entry points.
- **API** — FastAPI routers (scraping, templates, health, auth, captcha,
  admin, hosting portal), signed portal tokens, admin RBAC + audit log.
