# Architecture Decision Records (ADRs)

This directory documents the significant architectural decisions made in Pry.

## Process

1. When a significant decision is made, create a new ADR using `0000-template.md`
2. ADRs are numbered sequentially
3. Each ADR describes the context, decision, and consequences
4. ADRs are immutable — superseded ADRs get a new number with a reference
